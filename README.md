# Strumenti Digitali

Raccoglitore pubblico e indipendente di piattaforme digitali, curato da Elena Savkina.

## Contenuti

- ricerca e filtri per categoria;
- schede con link ufficiali;
- confronto fra strumenti;
- combinazioni consigliate;
- sezione blog e aggiornamenti;
- note legali separate.
- pagina “Meno costo, più flessibilità” con criteri prudenti e data di verifica.
- valutatore dimostrativo dei progetti, elaborato localmente senza invio dei dati.

## Pubblicazione

Il progetto è statico e non richiede installazione. Può essere pubblicato con GitHub Pages, Netlify o Cloudflare Pages selezionando la cartella principale del repository.

## Aggiornare le piattaforme

Le schede si trovano nell'array `tools` del file `script.js`. Per aggiungere una piattaforma, duplica una scheda e modifica nome, categoria, descrizione, collegamenti e URL ufficiale.
